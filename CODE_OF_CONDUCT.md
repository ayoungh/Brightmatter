# Code of Conduct

## Our commitment

We are committed to a welcoming, respectful, and harassment-free project for everyone, regardless of background, identity, experience, or ability.

## Expected behavior

- Be considerate, constructive, and specific.
- Critique ideas and code without attacking people.
- Respect different viewpoints and levels of experience.
- Accept feedback gracefully and correct mistakes openly.
- Protect private information and report security concerns responsibly.

## Unacceptable behavior

Harassment, threats, discrimination, sexualized conduct, deliberate intimidation, doxxing, sustained disruption, and other behavior that makes participation unsafe are not tolerated.

## Enforcement

Project maintainers may edit or remove contributions, comments, issues, or other participation that violates this code. They may also temporarily or permanently restrict participation when necessary.

Report conduct concerns privately to the maintainers through the repository owner's available GitHub contact channel. Reports will be reviewed with care and kept confidential where possible.

## Scope

This code applies in repository spaces and when someone is representing the project in public.
