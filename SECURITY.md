# Security Policy

## Supported version

Security fixes are applied to the latest version on the default branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability.

Use GitHub private vulnerability reporting from the repository's Security tab after the repository is created. Include:

- A clear description of the issue
- Steps or a minimal reproduction
- The potential impact
- Any suggested mitigation

The maintainer will acknowledge a complete report as soon as practical, investigate it, and coordinate disclosure when a fix is available.

General support questions and non-security bugs should use the normal issue templates.
